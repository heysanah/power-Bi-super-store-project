# Sales Performance Dashboard

## 🎯 Objective
The goal of this project is to analyze sales performance across different regions, customer segments, and product categories using interactive Power BI dashboards.  
This helps in identifying key trends, high-performing products, and areas needing improvement.

## 📊 Dataset
- **Source:** UPI Transactions 2024 Dataset (Kaggle) *(or mention your dataset source)*
- **Number of Rows:** 10,000+  
- **Number of Columns:** 15  
- **Key Columns:**  
  - `Order ID`, `Order Date`, `Ship Date`, `Customer Name`, `Segment`, `Region`, `Category`, `Sub-Category`, `Sales`, `Profit`, `Quantity`

## ⚙️ Steps to Reproduce
1. **Data Assessment & Cleaning**  
   - Import the dataset into Power BI or Excel  
   - Handle missing values, incorrect datatypes, and outliers  

2. **Dashboard Mockup Design**  
   - Design visual mockups (in PowerPoint or Figma) based on BRD/FRD  

3. **Build Power BI Dashboard**  
   - Import cleaned data into Power BI  
   - Create data model relationships  
   - Add visuals such as KPIs, Pie Charts, Funnel Charts, and Maps  

4. **Generate Reports & Insights**  
   - Export the Power BI visuals as PDFs or images  
   - Summarize key insights in an analysis report  

## 🧠 Key Insights (Example)
- Highest sales recorded in the **West Region**  
- **Technology** category contributed the most to overall profit  
- **Consumer Segment** showed steady growth over the months
